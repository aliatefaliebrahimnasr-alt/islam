# موقع مكتب محاماة — HTML + Firebase CMS

## ما الذي يمكن تعديله من لوحة التحكم؟
بعد تسجيل الدخول إلى `admin.html` يمكن تعديل:
- اسم المكتب والشعار وبيانات الاتصال والعنوان ومواعيد العمل.
- محتوى الصفحة الرئيسية والإحصائيات.
- قسم من نحن وصورة المحامي.
- إضافة/تعديل/حذف الخدمات.
- إضافة/تعديل/حذف مميزات المكتب.
- إضافة/تعديل/حذف المقالات وصورها.
- نصوص نموذج الاستشارة وأنواع الاستشارات.
- بيانات التواصل والفوتر.
- ألوان الموقع وإظهار/إخفاء الأقسام.
- عرض طلبات الاستشارة وتغيير حالتها أو حذفها.

## إعداد Firebase
1. فعّل Authentication > Sign-in method > Email/Password.
2. أنشئ مستخدم إدارة من Authentication > Users.
3. انشر قواعد Realtime Database الجديدة:
   `firebase deploy --only database`
4. انشر الموقع:
   `firebase deploy --only hosting`

المحتوى العام محفوظ تحت `siteContent` في Realtime Database، وطلبات العملاء تحت `consultations`.
الصور التي ترفع من لوحة الإدارة يتم ضغطها وحفظها كـ Data URL داخل `siteContent`، لذلك يفضل استخدام صور معقولة الحجم.
